# Terrova Landing - Çalışma Kuralları

1. **Dil**: Metinler ve içerikler Türkçe, kod (değişken/fonksiyon isimleri) İngilizce.
2. **Gizlilik**: API anahtarı, şifre gibi gizli bilgiler asla kod içine yazılmaz, .env dosyasında tutulur.
3. **Stil**: Sadece Tailwind CSS kullanılır, başka bir CSS kütüphanesi eklenmez.
4. **Commit**: Küçük ve anlamlı commit'ler yapılır, tek seferde büyük değişiklik gönderilmez.
5. **Yapı**: Mevcut proje yapısı takip edilir, yeni klasör/düzen icat edilmez.
