# Terrova Landing

Terrova tarım pazaryeri projesinin tanıtım sitesi. Terrova'nın ne olduğunu ve ne yaptığını anlatır.

Bu bir ürün değil, sadece bir tanıtım (landing) sayfasıdır. Kullanıcı işlemi yapılmaz, sadece Terrova anlatılır.

## Tech Stack

Next.js (App Router): Sitenin temel yapısı
TypeScript: Kod yazım dili
Tailwind CSS: Görünüm / stil
Vercel: Sitenin yayınlandığı yer

## Kurulum

1. Kütüphaneleri indir: npm install
2. Siteyi yerelde çalıştır: npm run dev
3. Tarayıcıda aç: http://localhost:3000

## Proje Yapısı

app/ klasörü sayfaların kodunu içerir
public/ klasörü resim ve ikon gibi statik dosyaları içerir

## Notlar

Bu proje şu an geliştirme aşamasındadır
.env gerektiren bir gizli bilgi henüz yoktur
